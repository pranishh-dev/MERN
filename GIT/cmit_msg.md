# Git Commit Message Types

**Format:** `type(scope): description`

- `feat` — Add new functionality.
  - `feat(dom): implement form submission`
- `fix` — Fix a bug.
  - `fix(js): correct filtering logic`
- `docs` — Update documentation or notes.
  - `docs(js): add closure notes`
- `refactor` — Improve code structure without changing behavior.
  - `refactor(dom): simplify event handlers`
- `wip` — Save unfinished work (informal convention).
  - `wip(js): save closure practice progress`

## Rules
- Commit after meaningful progress, not every tiny change.
- Use `wip` for unfinished lectures or assignments.
- Use `feat` for completed features or exercises.
- Keep messages short, descriptive, and consistent.
